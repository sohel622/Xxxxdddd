# Sohel APK Rename

Juno-র বানানো টুল আর রেকর্ড — APK-র ভেতরের "Instagram" / "InstaZen" লেখা বদলে **Sohel** করার জন্য।
এখানে শুধু নাম বদলানোর অংশটুকু আছে। অ্যাপের পুরো smali কোড এখানে নেই (ওটা Instagram/Meta-র নিজের কোড, আর ১.৯ GB)।

## কী কী আছে

| ফাইল | কাজ |
|---|---|
| `tools/rename_strings.py` | `resources.arsc`-এর string pool নতুন করে লেখে, আর সব "Instagram" লেখা "Sohel" করে দেয় (প্যাকেজ নাম, লিংক, ফাইলের নাম বাদ দিয়ে) |
| `tools/list_changes.py` | কোন কোন লেখা বদলাবে তার তালিকা বানায় |
| `tools/build_apk.sh` | আসল APK-তে নতুন `resources.arsc` বসায়, zipalign করে, নতুন key দিয়ে সাইন করে |
| `tools/patch_instazen_label.py` | InstaZen V8.5-এর অ্যাপ নাম "InstaZen" → "Sohel" (একই দৈর্ঘ্যে বাইনারি প্যাচ) |
| `changes/instagram_456_strings.tsv` | Instagram 456.0.0.53.78-এ যে ২০৭টা লেখা বদলানো হয়েছে, তার তালিকা (আগে => পরে) |

## দুটো APK

1. **Sohel_V8.5_32bit.apk** (২৩ নভেম্বর ২০২৬) — InstaZen V8.5 থেকে, শুধু অ্যাপের নাম আর ক্র্যাশ মেসেজ বদলানো। ৩২-বিট, তাই নতুন Android-এ চলে না।
2. **Sohel_IG_456_arm64.apk** (২৪ নভেম্বর ২০২৬) — Instagram 456.0.0.53.78 (৬৪-বিট) থেকে। অ্যাপের নাম সব ভাষায় Sohel, ভেতরের ২০৭টা লেখা বদলানো। মূল কোড (dex) ছোঁয়া হয়নি।

## যা বদলানো যায়নি

- হোম পেজের ওপরের "Instagram" লোগো — ওটা কোনো ছবি বা লেখা হিসেবে নেই, কোড নিজে আঁকে।
- `assets/strings/*.frsc` ফাইলের ভেতরের লেখা (Instagram-এর আলাদা চাপা দেওয়া string pack)।

## সতর্কতা

- নিজের ফোনে ব্যক্তিগত ব্যবহারের জন্য। অন্যকে দেওয়া বা বিক্রি করা যাবে না।
- বসাতে আসল অ্যাপ আনইনস্টল করতে হয়; Instagram লগইন আটকে দিতে পারে, অ্যাকাউন্ট ব্লকের ঝুঁকি আছে।
- সাইন করার key এই রিপোতে নেই, থাকবেও না।
